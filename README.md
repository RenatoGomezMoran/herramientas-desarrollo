# herramientas-desarrollo

## Nombre del proyecto: Sistema de gestión de requerimientos en empresa de Desarrollo  

## Descripción del proyecto: 

Este proyecto buscará la manera de implementar una solución tecnológica para el control de requerimientos de 
usuarios en una empresa de Desarrollo, para que así se tenga una mayor gestión y control del avance de cada uno con herramientas de proyección.
